# Happy Birthday Takia 💖

A responsive birthday surprise website with a personalized letter and optional background music.

## Files to keep together in the GitHub repository root

- `index.html`
- `style.css`
- `song.mp3`
- `1.png`
- `hat.png`
- `taki.png`
- `balloon1.png`
- `balloon2.png`
- `decorate_flower.png`
- `decorate.png`
- `smiley_icon.png`
- `heart.png`
- `cute2.png`

Image and audio filenames are case-sensitive and must match exactly. The decorative `cute2.png` appears inside the opened letter below the message, not above the birthday date.

## Music note

The page attempts to autoplay `song.mp3`. Mobile browsers may block autoplay with sound; in that case, tap the **Play Music** button.

## Publish with GitHub Pages

1. Upload all files above to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Open the published Pages URL after deployment completes.
